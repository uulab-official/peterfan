# Color runner strips

These 20 strips were generated with GPT Image for PeterFan and processed to
remove background noise and normalize each pose. Each PNG contains eight
48×32 RGBA frames in a single horizontal row. The application embeds the
strips at build time and retains the existing monochrome runner as a fallback.

Character identities follow the existing runner selections. The city strip
depicts the wheeled city and moving linkage used by the legacy runner.
