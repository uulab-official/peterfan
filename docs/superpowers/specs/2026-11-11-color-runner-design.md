# 컬러 러너 디자인

## 목표

기존 20종의 정체성과 동작을 유지하면서 입체감 있는 컬러 애니메이션으로 교체한다. 캐릭터별 프레임을 투명 배경으로 제작해 반복 재생하며, CPU 사용량에 따른 기존 속도 조절을 유지한다. 메뉴 막대와 설정 미리보기는 같은 프레임을 사용한다.

대상은 고양이, 강아지, 토끼, 여우, 펭귄, 공룡, 로봇, 유령, 새, 오리, 양, 물고기, 슬라임, 사람, 팔굽혀펴기, 행성, 초밥, 도시, 소시지, 파티다. 동물이 아닌 러너도 기존 주제와 움직임을 살린다.

## 방법

검토한 방법은 3D 모델에서 프레임 렌더링과 입체감 있는 2D 프레임 제작이다. 사용자가 제시한 후자를 채택한다. 캐릭터마다 동일한 형태, 색, 시점과 기준 위치를 유지하고 프레임 사이 및 마지막에서 처음으로 돌아가는 구간을 확인한다. 필요한 경우 제작 과정에서 모델링 도구를 보조적으로 사용할 수 있으나 실행 중 3D 렌더러는 필요하지 않다.

기존 캐시와 정규화, 프레임 선택, CPU 부하에 따른 속도 및 사용자 설정 호환성을 유지한다. 투명도, 크기와 기준선을 통일하되 각 캐릭터의 비율은 보존한다. 밝고 어두운 메뉴 막대에서 식별 가능하게 하고 작은 크기에서 실루엣과 움직임을 우선한다.

현재 공통 팩은 최종 48×32 RGBA, 동작당 8프레임, CPU 부하 4단계다. 기존 설정 식별자와 메뉴 막대·미리보기의 공통 팩을 보존하고 프레임은 미리 준비해 캐시한다. 부하 변화 시 재생 위상이 끊기지 않도록 기존 속도와 전환 로직을 유지한다. 물고기, 도시, 팔굽혀펴기처럼 달리기가 아닌 동작에는 달리기의 착지 기준을 일률적으로 적용하지 않고 각 동작에 맞게 검증한다.

## 검증

20종 전체의 프레임 시트와 실제 크기 반복 미리보기를 확인한다. 프레임 누락, 잘림, 위치 흔들림, 반복 경계와 색·형태 불일치를 검사한다. CPU 부하별 속도 변화와 설정 미리보기의 동일한 에셋 사용을 자동 검사하고, 실제 설치 UI에서 대상별 표시 및 동작을 확인한다. 관찰하지 못한 항목은 미검증으로 남긴다.

기존 앱 설정, 이전 릴리스, 사용자 파일과 실행 중인 앱을 보존한다. 배포와 설치는 별도의 검증을 거친다.
